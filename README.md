# What the brain reveals about a good Meta ad

Interactive writeup of an internal research study: running Meta's **TRIBE** model
(which predicts the brain's response to video) across 205 real Meta ecommerce ads,
to test which brain regions — lit up in an ad's first seconds — predict whether it
outperforms its brand's other ads.

**Live report:** https://derrickkwa.github.io/meta-ads-neuro-test/

Correlational, hypothesis-generating. No client names are included.
